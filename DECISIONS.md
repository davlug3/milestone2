# Decisions

- Units: meters.
- Coordinate convention (world): X = book width, Y = world up (book thickness), Z = book height (head-to-tail). Spine runs along Z at x = -width/2. Open book lies on the XZ plane; gravity is -Y. This supersedes PLAN.md section 3.1, which described an upright book and conflicted with gravity -Y for a book on a surface.
- Renderer: Three.js WebGLRenderer / WebGL 2.
- Physics: custom PBD/XPBD for the active page.
- Simulation timestep: fixed 1/120 second initially.
- Active dynamic pages: one initially.
- Final shot duration: 25 seconds.
- Final animation: deterministic and cacheable.
- Build system: Vite (no existing build system in repo at start).
- Language: TypeScript (strict).
- Folder layout: `src/app`, `src/config`, `src/book`, `src/paper`, `src/physics`, `src/animation`, `src/rendering`, `src/testing`, `src/assets`.
- Bending: two-step neighbor distance constraints (soft, stiffness ~0.35), configurable via `bendStiffness`. Dihedral bending deferred.
- Paper thickness: thin-shell render (front/back offset along mid-surface normal + perimeter edge), default 0.25 mm visual.
- Sim tests run headless via `npm run test:sim` (esbuild bundle + node).
- Sheet topology supports two rest planes: 'xy' (vertical, drop tests) and 'xz' (flat, page turns).
- Page turn: kinematic corner pin driven by `PageTurnController` (lift/peel/arch/cross/fall/settle via eased target); never rigid rotation. Ground collision (y clamp) for landing.
- Test scenes selectable via `?test=paper-drop|paper-edge|page-turn|book`; `?t=<seconds>` freezes a page-turn frame for deterministic screenshots.
- Page turn v2 (realism fix): drive the WHOLE fore-edge (not a single corner) along a semicircular arc of radius = page width about the gutter. Radius = width keeps the sheet at natural length so it never buckles into a gutter crease. High bending stiffness (1.0) + 12 solver iterations distribute curvature smoothly. After the sweep the fore-edge is held at its final rest position so the page settles on the destination (left) stack instead of crumpling. Objective smoothness verified via `npm run test:page` (worst dihedral 15.6 deg, stretch <=1.08x).
- Page turn v3 (curl + collision): liftScale 0.6 (real curl, not a rigid flat flip) + long-range bending constraints (3- and 4-cell spans) so curvature spreads across the sheet instead of buckling into one crease (dihedral 57 deg -> 29 deg at ~8 cm curl). Lowered the spine strip to page-block-top height so pages no longer intersect the spine mesh (was the "folds through binding" bug). Added shadow normalBias to kill shadow acne (dark triangles). Ground clamp at block-top height + per-page rising ground = pages rest on the book and stack without penetrating. Verified via `npm run test:page`: curl 7.9 cm, dihedral 29 deg, penetration 0, stretch <=1.07x, crosses fully and settles flat.
