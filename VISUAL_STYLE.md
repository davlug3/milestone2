# Visual styles
Luxury is the default for all five scenes. Select Classic from the style menu or add ?style=classic to a scene URL. The style is independent of quality, render mode, physics and render-pass selection. Luxury aligns lighting colors, exposure, emerald surroundings, champagne accents and photo-print finish. The hanging and floating real-time beauty renderers also use subtle bloom. Floating uses f/1.8 in Luxury, f/2.8 in Classic. Auxiliary passes remain ungraded. Existing offline exporters use Luxury by default. Physical motion blur, true volumetric scattering, film grain, HDR AOVs and advanced camera choreography are not part of this first implementation.
